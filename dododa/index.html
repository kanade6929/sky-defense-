怎么玩HOW TO PLAY
1

鼠标指哪打哪

鼠标决定朝向。左键近战（连点 3 下是重击），右键音波弹。跟着节拍按，伤害更高、地面浮得更高；打败怪物会回血。按不准也不会被罚。狂点没用：每个键最快半拍出一下，跟着拍子按最强。

左键右键
2

按出连招

一拍按一下，按出固定顺序就会放技能。比如 左、左、右：向前冲锋拳。开卡包能学到新连招。

左左右
3

左右键一起按

平时是音障：把身边的弹幕全部弹回去。连招越多 GROOVE 越高，槽满后在小节第一拍一起按就是 DROP，全屏大招，整条街一起变色。Boss 防御时打不动，等它出完招露出破绽再踩拍输出。

安装INSTALL
  1. 点上面的黄色按钮，下载 DODODA-win.zip（约 80MB）。
  2. 右键 → 全部解压缩，放到任意文件夹（解压后约 155MB）。
  3. 双击 DODODA.exe。如果 Windows 提示“已保护你的电脑”，点 更多信息 → 仍要运行（试玩版没有签名证书）。
  4. 节拍听起来对不上？在 Esc → 设置 → 延迟校准 里跟着节拍按几下，会自动调好。
